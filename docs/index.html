Desktop Companion for Plone Sites

Ploa Your Plone Desktop Companion

A native desktop application that makes managing Plone sites faster and easier. Connect to your Plone site, browse content, manage tags, and edit blocks—all from a dedicated app designed for efficiency.

Download Now View on GitHub

Key Features

Quick Access

Open the app and instantly connect to your Plone site. No need to open a browser or navigate through multiple tabs.

Remember Last Site

Ploa remembers the last site you visited, so you can easily reconnect and pick up where you left off.

Fast Content Browsing

Navigate through folders and view item details quickly. Browse your Plone content structure with ease.

Tag Cleanup Tools

Find and merge duplicate or similar tags across your entire site. Fix typos, standardize capitalization, and consolidate related tags.

Visual Block Editing

Edit Plone content blocks with a visual interface. Drag and drop to reorder blocks, or edit directly in JSON mode.

Native Desktop App

A dedicated desktop application for Plone content management. No browser tabs needed—just launch the app and connect to your Plone site.

Latest Release Notes

v1.1.23 - Upgrade Steps Management

January 30, 2026

⚡ Upgrade Steps Management
  • Upgrade Panel – New "Upgrades" button opens a dedicated panel to view and manage Plone upgrade steps.
  • Version Status – See filesystem vs. instance version at a glance with clear upgrade indicators.
  • Selective Upgrades – Select individual steps or entire version ranges with checkbox controls.
  • Dry Run Option – Preview upgrade effects before committing changes.
📊 Enhanced Content Statistics
  • Browse by Type – Click any content type in the Content Statistics report to instantly filter and browse items of that type.

v1.1.22 - Keyword Management Modal

December 6, 2025

🏷️ Enhanced Keyword Management
  • Item Keyword Modal – Click any item in the keyword manager accordion to open a dedicated modal for managing keywords on that specific item.
  • Quick Keyword Editing – Add or remove keywords directly from the modal with an intuitive interface.
  • Keyword Browser – View all existing keywords and quickly add them to items with a single click.
  • Visual Feedback – See current keywords as removable tags and get instant confirmation when changes are saved.

v1.1.21 - Content Stats & UX Improvements

December 5, 2025

📊 Content Stat Browser
  • Visualize Content – View a breakdown of all content types in your site.
  • Quick Filtering – Click any content type in the stats table to instantly filter search results.
✨ UX Enhancements
  • Home Navigation – Clicking the Ploa logo now takes you to the root folder.
  • Bug Fixes – Resolved build issues and improved stability.

v1.1.20 - RAG Chat & Content Filters

December 5, 2025

💬 RAG Chat
  • Chat with Documents – Immediately chat with your bundled PDFs using a local LLM (Ollama) or OpenAI.
  • Model Discovery – Automatically detects installed Ollama models for easy selection.
🔍 Enhanced Search
  • Content Type Filter – Filter search results by type (e.g., News Item, Folder).
  • Performance – Optimized anonymous search for faster results.

v1.1.19 - Download Diagnostics & Reliability

December 2, 2025

📊 Enhanced Diagnostics
  • "Learn More" Panel – Detailed breakdown of download results, showing exactly why files were skipped or failed.
  • Direct Access Links – "Open ↗" links for failed items let you verify access permissions directly in your browser.
🔒 Robust Authentication
  • Fixed 401 errors for protected files by improving URL handling and authentication headers.
  • Added support for cookie-based JWT authentication for broader server compatibility.

v1.1.17 - RAG Bundle Reliability

November 27, 2025

📦 Smarter PDF Bundles
  • Live progress indicator – shows how many PDFs have downloaded and how many are still pending.
  • Resume failed downloads – automatically queue only the PDFs that need another attempt.
  • Failure insight – the bundle card now lists sample errors (missing permissions, not found, etc.) so you know why something didn’t save.
🔍 Search & Preview Improvements
  • Full-object search responses ensure `file.download` metadata is available for reliable PDF detection.
  • Secure preview proxy uses your authenticated session for protected documents.
